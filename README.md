# 90 天家中徒手健身计划

一个**纯静态、零依赖、可离线运行**的健身计划 App。输入性别与目标后，自动生成 90 天的每日训练动作、组数次数、饮食热量与宏量营养素方案，支持打卡、计时与体重追踪。

无需安装、无需联网、无需后端，双击 `index.html` 即用。所有数据保存在浏览器 `localStorage`，不会上传到任何服务器。

## 快速开始

### 本地使用

```bash
# 方式一：直接双击 index.html
# 方式二：起一个本地服务（推荐，避免个别浏览器的 file:// 限制）
python -m http.server 8000
# 然后打开 http://localhost:8000
```

### 发布到 GitHub Pages

1. 在 GitHub 新建仓库，把本目录内容推上去：

```bash
git init
git add .
git commit -m "feat: 90天家中徒手健身计划"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

2. 进入仓库 **Settings → Pages → Build and deployment**
3. Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`
4. 保存，稍等 1-2 分钟即可访问 `https://<用户名>.github.io/<仓库名>/`

也可直接把 `index.html` 丢到任意静态托管（Vercel / Netlify / 腾讯云静态网站 / 对象存储），无需构建步骤。

## 功能

| 模块 | 内容 |
| --- | --- |
| 今日训练 | 自动推算今天是第几天，给出热身、主训练（每个动作含**动画演示 + 标准做法四步**、要点、难易调节）、放松拉伸 |
| 90 天计划 | 三阶段说明、13 周周视图、点击任意一天查看当天安排 |
| 饮食 | BMR/TDEE/目标热量、三大宏量营养素、一日餐单示例、食物交换份表、男女差异化要点 |

## 动作标准做法

展开每个动作，会看到「标准做法」四步卡：

| 项 | 说明 |
| --- | --- |
| **起始** | 怎么摆位——手距、脚距、身体角度、支撑点 |
| **过程** | 怎么动——发力顺序、幅度、节奏、顶峰停顿 |
| **呼吸** | 何时吸气、何时呼气（憋气会升高血压，用力段呼气） |
| **别犯** | 该动作最常见的 1-3 个错误与代偿 |

主训练区顶部还有适用于所有动作的三条通则：**下放（离心）控制 2-3 秒 · 顶点不锁死关节 · 姿势变形就结束这一组**。

61 个动作全部配有标准做法，男女共用同一套要领（执行差异已体现在动作选择与组数里）。

要领写在 `js/form.js` 的 `FORMS` 里，按动作名片段匹配（`FORM_MATCH`）；想修改某个动作的说法，直接改对应条目即可。

## 动作演示

每个动作展开「▶ 动作演示」后，会播放一段**矢量骨架动画**（循环播放，点击可暂停）。

- 覆盖 **57 / 61** 个动作（未覆盖：俯卧 Y-T-W、壁面肩胛滑动、凯格尔、熊爬）
- 深蓝为近侧肢体，浅蓝为远侧肢体；灰色道具表示椅子、台阶、桌面、墙
- 动画只在展开时播放，不展开不耗电；设置里可整体关闭

### 为什么不是真人动图

- 网上健身 GIF 多数有版权，且会让仓库体积暴涨、离线打不开
- 自绘 SVG 动画：零依赖、离线可用、约 10 KB、可无限缩放

### 想换成真人 GIF / 视频

在 `js/pose.js` 的 `POSES` 里给对应动作加一行 `img` 即可，渲染器会优先显示图片：

```js
squat: {
  label: '徒手深蹲', tip: '...',
  img: 'assets/squat.gif',     // 加这一行，骨架动画自动让位给图片
  f: [ ... ]
},
```

记得把图片放进 `assets/` 目录。建议宽度 ≤ 360px、体积小、循环播放的 GIF 或 WebP。

## 训练方案

### 一周分化

| 周几 | 部位 | 训练模式 |
| --- | --- | :--- |
| 周一 | 胸 · 三头 | 水平推 + 肘伸 |
| 周二 | 背 · 二头 | 水平拉 + 肩胛后缩 |
| 周三 | 腿 · 臀（前链） | 蹲 |
| 周四 | 肩 · 核心 | 肩三束 + 核心抗屈/抗旋 |
| 周五 | 下肢后链 · 臀腿 | 髋铰链 |
| 周六 | 全身代谢循环 + 核心 | HIIT 循环 |
| 周日 | 完全休息 | 主动恢复 |

### 三阶段渐进超负荷

| 阶段 | 天数 | 组数 | 强度 | 重点 |
| --- | --- | :---: | :---: | --- |
| 一 | 1-30 | 3 组 | RPE 6-7 | 建立动作模式与关节耐受 |
| 二 | 31-60 | 4 组 | RPE 7-8 | 提升总容量，引入单腿与慢速离心 |
| 三 | 61-90 | 4 组 | RPE 8-9 | 节奏变化、超级组、递减组突破平台 |

- **减量周**：第 4 / 8 / 12 周整周少 1 组、强度降至 5-6 成。疲劳累积到临界点后主动减载，才会发生超量恢复。
- **自测日**：减量周的周六做 1 分钟俯卧撑 / 深蹲 / 平板 / 单腿臀桥自测，数据自动留存用于纵向对比。
- **RPE**：主观用力程度（10 分制）。RPE 7 表示"每组还能多做 3 个"。

### 男女分案

| | 男性方案 | 女性方案 |
| --- | --- | --- |
| 容量倾向 | 上肢推拉各 6-7 个动作 | 臀腿 8-9 个动作 |
| 推力起步 | 标准俯卧撑 | 上斜 / 跪姿俯卧撑 |
| 特色内容 | 深蹲跳、波比跳等爆发力动作 | 臀中肌（侧卧抬腿、蚌式）、盆底凯格尔 |
| 额外提示 | 别忽视后链与柔韧 | 生理周期强度调节（卵泡期冲强度，黄体期降 10-15%） |

差异依据：女性髋部更宽、Q 角更大，需强化臀中肌以改善膝内扣；上肢绝对力量约为男性 50-60%，推力降阶起步更合理；女性睾酮水平约为男性 1/15，徒手训练不会"练成大块头"。

## 饮食方案

- **BMR**：Mifflin-St Jeor 公式
  - 男：`10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5`
  - 女：`10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 − 161`
- **TDEE**：BMR × 1.55（每周 6 天中等强度训练）

| 目标 | 热量 | 蛋白质 | 脂肪 |
| --- | --- | :--- | :--- |
| 减脂（男） | TDEE − 500 | 2.0 g/kg | 0.8 g/kg |
| 减脂（女） | TDEE − 350 | 1.8 g/kg | 0.9 g/kg |
| 增肌（男） | TDEE + 350 | 1.8 g/kg | 1.0 g/kg |
| 增肌（女） | TDEE + 250 | 1.6 g/kg | 1.0 g/kg |
| 塑形 / 维持 | TDEE | 1.6-1.7 g/kg | 0.9 g/kg |

碳水由剩余热量填充。设有安全下限（男 ≥1500 kcal、女 ≥1200 kcal）。

女性缺口刻意压到 350 kcal、脂肪不低于 0.9 g/kg：缺口过大或脂肪过低会影响雌激素合成，导致掉发、月经紊乱与反弹。

另含：食物交换份表（按"份"自由搭配，不重样）、训练日/休息日碳水调整、每 4 周复评规则、男女各自的执行要点。

### 想改内容怎么办

几乎不用碰 `app.js`，改 `js/data.js` 即可：

- `DAYS` —— 每天的动作数组，`male` / `female` 两份；`r: [阶段1次数, 阶段2次数, 阶段3次数]`，`cue` 是要点，`down` / `up` 是降阶与进阶
- `PHASES` —— 三阶段的组数、组歇、RPE、HIIT 轮数
- `DELOAD` —— 减量周自测日内容
- `WARMUP` / `COOLDOWN` —— 热身与放松
- `calcDiet()` —— 热量与宏量参数
- `FOOD_EXCHANGE` / `MEAL_PLANS` —— 食物交换份与示例餐单
- `js/pose.js` 的 `POSES` —— 动作演示的关键帧坐标；`POSE_MATCH` —— 动作名到动画的匹配规则
- `js/form.js` 的 `FORMS` —— 每个动作的标准做法；`FORM_MATCH` —— 动作名到要领的匹配规则

## 技术说明

- 原生 HTML + CSS + JavaScript，**无任何第三方库、无构建步骤、无网络请求**
- 图表用 Canvas 手绘，不依赖 Chart.js
- 提示音用 Web Audio API 生成，不加载音频文件
- 数据存 `localStorage`（键名 `bw90_state_v1`），换浏览器或清缓存会丢失，设置页可一键清空
